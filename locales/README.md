# 本地化资源说明

本目录用于存放中文化资源与翻译规范产物，目标是将文案改动集中在可维护的层，便于同步上游后重放。

## 结构
- `locales/zh-CN.json`：中文资源主文件。
- `docs/zh/`：中文文档与翻译规范。

## 资源格式
`zh-CN.json` 使用如下结构：

```
{
  "meta": { ... },
  "strings": {
    "module.context.message_key": "中文翻译"
  }
}
```

## 约定
- Key 采用分层命名（模块.上下文.语义）。
- 保留变量占位符，使用 `{name}` 形式。
- CLI 参数、命令、文件路径保持原样，不翻译。
- 新增或更新翻译时请同步更新 `meta.last_sync`。
